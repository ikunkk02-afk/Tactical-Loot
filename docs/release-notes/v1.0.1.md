# Tactical Loot v1.0.1

Tactical Loot 1.0.1 正式发布。

本版本完成了主要拾取流程、战利品管理界面与 UI 自定义系统的发布整理和稳定性验证。玩家可以在世界 HUD 中查看附近掉落物，也可以通过独立界面进行快速拾取、指定槽位放置与重新丢弃。

## 主要功能

- 世界内附近战利品 HUD，最多同时显示 6 组物品
- 战利品目标选择、切换与数量调整
- 大型战术拾取界面，分区显示玩家背包和附近战利品
- 按名称或物品 ID 搜索战利品
- `Shift + 鼠标右键` 快速拾取整组物品
- 将战利品拖到指定背包槽位
- 将背包物品重新丢弃到附近战利品区域
- `Normal`、`Low Priority` 与 `Hidden` 物品过滤状态
- Minecraft 风格的深色界面与克制的交互动画
- 战利品 HUD 位置与大小调整
- 大型战术拾取界面位置与比例调整
- 两套 UI 独立编辑、自动保存与恢复默认
- 服务端对拾取和丢弃请求进行实时验证

## v1.0.1

1.0.1 是当前正式发布版本。本版本重点完善了 UI 自定义能力，并完成发布前的界面、交互、配置持久化与稳定性整理。

## 运行环境

- Minecraft 1.21.1
- NeoForge 21.1.248 或兼容的 21.1.x 版本
- Java 21 或更高版本

多人游戏中，客户端和服务端都需要安装版本一致的 Tactical Loot。

## 下载校验

- 文件：`TacticalLoot-1.0.1-neoforge-1.21.1.jar`
- SHA256：以本分支构建产物为准
