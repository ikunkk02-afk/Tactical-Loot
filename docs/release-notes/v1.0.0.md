# Tactical Loot v1.0.0

Tactical Loot（战术拾取）第一次正式版本发布。

这是一个重新设计 Minecraft 地面掉落物拾取体验的 Fabric 模组。相比直接走到物品上自动拾取，Tactical Loot 会把玩家附近的掉落物整理为可以查看、选择和管理的战利品，让拾取大量物品时更直观。

## 主要功能

- 检测并聚合玩家附近的地面掉落物
- 通过世界内 HUD 显示物品图标、名称、数量、附魔信息和操作提示
- 使用默认 `F` 键进入拾取模式并确认拾取，通过滚轮切换目标
- 使用 `Shift + 滚轮` 或 `Ctrl + Shift + 滚轮` 调整拾取数量
- 使用默认 `H` 键打开战术拾取界面，分区显示玩家背包与附近战利品
- 支持战利品搜索、详情查看、数量选择和滚动浏览
- 使用 `Shift + 鼠标右键` 快速拾取整组战利品
- 将战利品拖到指定背包格，并由服务端验证物品兼容性和槽位容量
- 将背包物品拖回附近战利品区域，重新丢弃到世界并保留 Data Components
- 提供 `Normal`、`Low Priority` 和 `Hidden` 三种物品过滤状态及独立管理界面
- 使用 Minecraft 风格的深色 UI，以及打开、关闭、悬停、切换和拾取反馈动画
- 所有拾取与丢弃操作均由服务端根据实时世界和背包状态重新验证

## 运行环境

- Minecraft 1.21.1
- Fabric Loader 0.19.3 或更高版本
- Fabric API 0.116.15+1.21.1 或更高的 Minecraft 1.21.1 兼容版本
- Java 21 或更高版本
- Mod Menu 11.0.4 或更高版本（可选）

多人游戏中，客户端和服务端都需要安装 Tactical Loot 与 Fabric API。

## 关于 1.0.0

1.0.0 是 Tactical Loot 的第一个正式公开版本，目标是提供一套稳定、直观，并尽量保持 Minecraft 原版操作风格的附近战利品管理体验。
