# Tactical Loot - 战术拾取

## 简介

Tactical Loot（战术拾取）是一款重新设计 Minecraft 地面掉落物拾取与管理方式的 Forge 模组。

当附近存在掉落物时，模组会通过世界 HUD 显示物品图标、名称、数量和操作提示。玩家可以切换不同目标，也可以打开专门的战术拾取界面，在附近战利品与自己的背包之间进行更精确的物品管理。

模组会阻止玩家通过碰撞自动吸取掉落物。所有拾取和丢弃操作均由服务端根据实时距离、物品状态、拾取延迟与背包容量验证。

## 主要功能

- 检测并聚合玩家 5 格范围内的地面掉落物
- 世界 HUD 最多同时显示 6 组战利品
- 显示物品图标、名称、数量、附魔信息和操作提示
- 使用滚轮选择目标，并按 1 或 16 调整拾取数量
- 大型战术拾取界面分区显示玩家背包与附近战利品
- 支持按本地化名称或物品 ID 搜索
- 使用 `Shift + 鼠标右键` 快速拾取整组物品
- 将战利品拖入指定背包槽位
- 将背包物品重新丢弃到战利品区域
- 使用优先级与隐藏状态管理不需要关注的物品
- Minecraft 风格的深色界面与短时间交互动画

## UI 自定义

v1.0.1 提供两套相互独立的 UI 编辑器。玩家可以调整战利品 HUD 与大型战术拾取界面的位置和比例，单独恢复默认设置，或一次恢复全部 UI。

默认按 `U` 打开 Tactical Loot 设置。进入对应编辑器后，按住鼠标左键拖动界面，将鼠标停在预览上并滚动滚轮即可调整大小；按 `Esc` 保存并返回游戏。安装 Mod Menu 后，也可以从模组列表的配置按钮进入设置。

UI 配置只保存在客户端，不会同步到服务器或写入世界存档。

## 操作方式

| 操作 | 默认输入 |
| --- | --- |
| 进入拾取模式 / 确认拾取 | `F` |
| 切换战利品 | 拾取模式中滚轮 |
| 调整拾取数量 | `Shift + 滚轮` |
| 按 16 调整拾取数量 | `Ctrl + Shift + 滚轮` |
| 打开战术拾取界面 | `H` |
| 快速拾取整组战利品 | `Shift + 鼠标右键` |
| 打开 Tactical Loot 设置 | `U` |
| 打开过滤管理 | `O` |
| 切换当前物品过滤状态 | `X` |

`F` 复用 Minecraft 原版“切换副手”按键绑定。所有自定义按键均可在控制设置中重新绑定。

## 安装要求

- Minecraft 1.20.1
- Minecraft Forge 47.4.23
- Java 17 或更高版本
- Mod Menu 11.0.4 或更高版本（可选）

将 Tactical Loot 的 Forge 正式 JAR 放入游戏实例的 `mods` 目录后启动游戏。多人游戏中，客户端与服务端都需要安装相同版本的 Tactical Loot。

## 注意事项

- 此分支支持 Minecraft 1.20.1 Forge 47.4.23
- Mod Menu 不是必要依赖；不安装时仍可通过默认按键使用设置和过滤功能
- 被隐藏或降低优先级的地面物品不会被删除，水流、漏斗和物品寿命等行为仍由 Minecraft 处理
- 问题反馈：[GitHub Issues](https://github.com/ikunkk02-afk/Tactical-Loot/issues)
